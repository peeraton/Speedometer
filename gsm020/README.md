# GSM020 Tracker (Android)

แอป Android สำหรับ SkyRC GSM020: เชื่อมต่อผ่าน Bluetooth LE, วาดเส้นทางบนแผนที่ โดยใช้สีบอกความเร็ว, แตะจุดบนเส้นทางเพื่อดูความเร็ว เวลา ความเร่ง และพิกัด, ส่งออกเป็น CSV/GPX

## วิธีที่ 1: Build บน GitHub (ไม่ต้องมีคอม)

1. สมัคร/ล็อกอิน github.com แล้วสร้าง repository ใหม่
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github` ด้วย)
3. ไปที่แท็บ **Actions** รอ "Build APK" ขึ้นเครื่องหมายถูกสีเขียว (ประมาณ 5–10 นาที)
4. กดเข้าไปที่งานนั้น ดาวน์โหลด **gsm020-tracker-apk** (เป็น zip ข้างในมีไฟล์ `app-release.apk`)
5. แตกไฟล์แล้วติดตั้ง APK บนมือถือ (อนุญาต "ติดตั้งแอปที่ไม่รู้จัก")

## วิธีที่ 2: Build บนคอม

ต้องมี Flutter 3.24 ขึ้นไป และ Android SDK

```bash
flutter create --org com.example --project-name gsm020_tracker --platforms=android .
cp android_overrides/AndroidManifest.xml android/app/src/main/AndroidManifest.xml
rm -f test/widget_test.dart
flutter pub get
flutter run            # ต่อมือถือผ่าน USB
flutter build apk      # หรือสร้างไฟล์ APK
```

## การใช้งาน

1. เปิด GSM020 และ **ปิดแอป RC Gears** (เครื่องต่อได้ทีละแอป)
2. กด "เชื่อมต่อ GSM020" อนุญาตสิทธิ์ "อุปกรณ์ใกล้เคียง" แล้วเลือกเครื่อง
3. รอไฟเขียว (GNSS fix) ที่เครื่อง เส้นทางจะเริ่มขึ้นบนแผนที่
4. เมนู ⋮ มีส่งออก CSV/GPX, ล้างเส้นทาง และโหมดทดลอง

## แชร์ลิงก์ให้เครื่องอื่นดูสด

มือถือที่ต่อ GSM020 จะส่งตำแหน่งและความเร็วขึ้นอินเทอร์เน็ตประมาณ 5 ครั้งต่อวินาที
คนดูเปิดลิงก์ในเบราว์เซอร์ใดก็ได้ (คอม แท็บเล็ต มือถือ) ไม่ต้องติดตั้งแอป

ตั้งครั้งเดียว: เปิดหน้าเว็บสำหรับคนดูด้วย GitHub Pages (ฟรี)
1. ใน repository ไปที่ **Settings > Pages**
2. Source เลือก **Deploy from a branch**, Branch เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
3. รอ 1–2 นาที หน้าเว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/viewer/`

ใช้งาน:
1. ในแอปกดไอคอนแชร์สด (รูปคลื่น) ที่แถบด้านบน
2. ใส่ที่อยู่หน้าเว็บจากขั้นตอนด้านบน (ใส่ครั้งเดียว แอปจำไว้)
3. เปิดสวิตช์ "ส่งข้อมูลสด" แล้วกด "ส่งลิงก์" ผ่าน LINE หรือแอปอื่น
4. คนที่เปิดลิงก์ระหว่างรถกำลังวิ่ง จะเห็นเส้นทางย้อนหลังด้วย

ข้อควรรู้:
- ข้อมูลผ่านเซิร์ฟเวอร์ MQTT สาธารณะ `broker.emqx.io` ใครที่รู้รหัสห้องจะดูได้ กด "สุ่มรหัสใหม่" เมื่อต้องการยกเลิกลิงก์เดิม
- มือถือที่ต่อ GSM020 ต้องมีเน็ต และต้องอยู่ในระยะบลูทูธของรถ (ประมาณ 10–50 m)
- ถ้าต้องการความเป็นส่วนตัวมากขึ้น เปลี่ยนเป็นเซิร์ฟเวอร์ MQTT ของตัวเองได้ที่ `lib/live.dart` และ `viewer/index.html`

## ข้อมูลที่ GSM020 ส่งมา

ถอดจาก log ของแอป RC Gears (ชื่อแพ็กเกจ com.skyrc.weight):

- ชื่อบลูทูธ: `GPSspeed`, service `fff0`, ส่งคำสั่งที่ `fff3`, รับการตอบกลับที่ `fff4`
- **คำสั่งเริ่มทำงาน** = ตั้งเวลา (UTC): `0f 0e 0b 00 วินาที นาที ชั่วโมง วัน เดือน ปี(2 ไบต์) 00 00 00 00 checksum ff ff`
  โดย checksum = (ผลรวมไบต์ที่ 2–14 + 1) & 0xFF
- ข้อมูลสด: อ่าน (READ) 16 ไบต์ ซ้ำประมาณ 4–10 ครั้งต่อวินาที
  - ไบต์ 0 = สถานะ GNSS (0 = ยังไม่จับสัญญาณ), ไบต์ 2 = จำนวนดาวเทียม, ไบต์ 6 = 1 คือสัญญาณหลุด
  - ไบต์ 7–8 = ความเร็ว (big-endian) ÷ 100 = km/h
  - ไบต์ 9–10 = ระยะทาง (big-endian) ÷ 10 = เมตร
- **GSM020 ไม่ส่งพิกัด** แผนที่จึงใช้ GPS ของมือถือ (เปิดได้ที่ปุ่ม "GPS มือถือ") ใช้ได้เมื่อมือถืออยู่บนรถหรือเคลื่อนที่ไปกับรถ

## เว็บแอป (ไม่ต้องติดตั้ง)

`index.html` คือเว็บแอปเวอร์ชันเดียวกัน เมื่อเปิด GitHub Pages แล้วจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`
เปิดด้วย Chrome บน Android กด "เชื่อมต่อ GSM020" ได้เลย

## หมายเหตุ

- หน้าจอจะเปิดค้างไว้ระหว่างเชื่อมต่อ เพื่อให้รับข้อมูลต่อเนื่อง
- ความเร่งคำนวณจากความเร็วที่เปลี่ยนไปตามเวลา และกรองสัญญาณรบกวนแล้ว
- แผนที่จาก OpenStreetMap ต้องใช้อินเทอร์เน็ต
